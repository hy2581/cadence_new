// 点积阵列 — 中文伪代码（对应 dot_product_array.sv）
// ============================================================

模块: 点积阵列
功能: 计算 S = Q分块 · K分块^T，得到 Q行×KV列 的分数矩阵
      数据分 总步数 = 头维度/并行乘累加数 步流入，每步每行给 并行乘累加数 个元素

状态: 空闲 | 累加中 | 缩放中 | 完成状态

寄存器:
  累加器[Q行][KV列]
  步计数

复位:
  状态=空闲, 步计数=0, 累加器全 0, 完成/忙碌/分数有效 清零

主循环 每个时钟上升沿:
  默认: 分数有效=0, 完成=0

  状态 空闲:
    若 启动:
      状态=累加中, 步计数=0, 忙碌=1, 累加器清零

  状态 累加中:
    若 数据有效:
      对每个 Q行 r、KV列 c:
        部分和 = Σ_{p=0}^{并行数-1} Q[r][p] × K[c][p]   // 宽位乘加
        累加器[r][c] += 部分和
      步计数++
      若 步计数 == 总步数-1（最后一步已处理）:  // 注意 RTL 在==总步数-1时转缩放
        下一状态 = 缩放中

  状态 缩放中:
    对每个 r,c:
      分数矩阵[r][c] = (累加器[r][c] × 缩放因子) 算术右移 8   // 与 Q 格式对齐
    状态 = 完成状态

  状态 完成状态:
    分数有效=1, 完成=1, 忙碌=0, 状态=空闲
