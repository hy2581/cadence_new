// 以下为“配置常量表”，综合/仿真前由头文件注入，此处用自然语言复述：

维度与分块:
  序列长度 = 256
  头维度 d = 64
  Q 每分块行数 = 4
  KV 每分块行数 = 16
  由此 Q 分块个数 = 序列长度 / Q 每分块行数
       KV 分块个数 = 序列长度 / KV 每分块行数

数据格式:
  数据位宽 = 16（如 Q8.8 定点）
  小数位 = 8
  累加器位宽 = 40（点积中间结果防溢出）
  指数输出位宽 = 24
  分数中间位宽 = 40

AXI:
  AXI 地址位宽 = 64，数据位宽 = 128，ID 位宽 = 4
  AXI4-Lite 地址位宽 = 8，数据位宽 = 32
  写选通位宽 = 数据位宽/8

寄存器地址映射（偏移）:
  0x00 控制 | 0x04 状态 | 0x08 配置
  0x14~0x30 Q/K/V/O 基地址低/高各 32 位
  0x34 行步长 | 0x38 负大值 | 0x3C 缩放因子 | 0x40 周期计数

控制/状态/配置位语义:
  控制: 位0 启动脉冲，位1 软复位脉冲，位2 中断使能
  状态: 位0 忙碌，位1 完成（粘滞），位2 错误
  配置: 位0 因果掩码使能

默认值:
  行步长 = 头维度×2 字节
  负大值、缩放因子为固定默认定点常数（与 RTL 中一致）

并行度:
  并行乘累加数 = 8（每周期同时累加 8 个乘积）

指数相关表参数:
  倒数单元用 LUT 深度 256、位宽 16 等（与 RTL 注释一致）
