# 指数查找表十六进制（`exp_lut.hex`）

对应 RTL：`rtl/include/exp_lut.hex`。

---

## 文件性质

在 RTL/仿真中，本文件通常是 **纯文本十六进制**：**每行一个常数**，按 **地址递增顺序** 排列，用于 **指数查找表 ROM** 的初始化（`$readmemh` 或综合存储器初始化）。

伪代码不重复罗列全部常数，只说明 **每行数学含义**，便于你对照波形或改表。

---

## 数学映射（概念伪代码）

```text
对于地址 index = 0 .. 1023-1（具体行数以实际 hex 行为准）:
  实数 x = -16 + index × (20 / 1024)   // 将 index 映射到 [-16, +4] 区间
  存储值 ≈ round( exp(x) × 65536 )     // 定点缩放后写入（位宽与 exp_lut_rom 一致）
  若超过最大可表示值则饱和为全 1
```

### 分段说明

1. **定义域 `[-16, +4]`**：覆盖 Softmax/指数近似中常见的 **负指数主导** 区间；上界取 **+4** 是因为 `exp(4)` 已较大，再往上可由 **饱和或另一段逼近** 处理（以 RTL 为准）。
2. **1024 点**：深度 1024 时步长约为 `20/1024`，索引均匀采样。
3. **`× 65536`**：典型 **16.16 或归一化到整数域** 的定点缩放；若 ROM 数据位宽为 **24 bit**（见参数头文件），则是 **截断/饱和到 24 bit** 后的结果。
4. **饱和**：防止 `exp(x)` 放大后超出可表示范围导致 **回绕错误**。

---

## 与硬件的对应关系

- **地址**：当前查表输入（经 **指数近似单元** 量化/截取后的 index）驱动 ROM 地址。
- **数据**：读出值进入 **乘法/移位** 链，与 **在线 Softmax** 中的 **分子/分母更新** 结合。

---

## 注意

- **具体数值必须以仓库中的 `rtl/include/exp_lut.hex` 为准**；若你修改采样区间、深度或位宽，需 **重算全表** 并同步 **`fa_params` / ROM 深度 / 寻址位宽**。
- 若行数不是 1024，将上式中的 **`1023-1`** 与 **`20/1024`** 改为 **实际深度** 与 **实际区间长度**。
