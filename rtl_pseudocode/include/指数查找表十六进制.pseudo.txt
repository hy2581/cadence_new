// 本文件在 RTL 中为纯十六进制文本：每行一个值，按地址顺序排列，
// 用作指数查找表 ROM 的初始化数据（或仿真/综合加载）。

伪代码含义:
  对于地址 index = 0 .. 1023-1（具体行数以实际 hex 行为准）:
    实数 x = -16 + index × (20 / 1024)   // 将 index 映射到 [-16, +4] 区间
    存储值 ≈ round( exp(x) × 65536 )     // 定点缩放后写入 24 位（与 exp_lut_rom 一致）
    若超过最大可表示值则饱和为全 1

注意:
  具体数值以 rtl/include/exp_lut.hex 为准；此处仅描述“每行是什么含义”，
  不重复列出全部 1024 个十六进制常数。
