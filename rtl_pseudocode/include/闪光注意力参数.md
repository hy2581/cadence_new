# 闪光注意力参数（`fa_params.svh`）

对应 RTL：`rtl/include/fa_params.svh`。  
本文件在工程中为 **`include` 头文件**；此处用自然语言复述其 **可配置常量与寄存器语义**，便于阅读伪代码与文档时对照。

---

## 维度与分块

```text
序列长度 = 256
头维度 d = 64
Q 每分块行数 = 4
KV 每分块行数 = 16
由此:
  Q 分块个数 = 序列长度 / Q 每分块行数
  KV 分块个数 = 序列长度 / KV 每分块行数
```

**解析**：

- **序列长度**：参与注意力的 token 数（或最大支持长度，视实现）。
- **Q 小块行数** 通常 **≤ KV 小块行数**：FlashAttention 外层循环常按 **Q 条查询** 与 **KV 一条带** 组织，以减少片上缓冲。
- **分块个数**决定外层循环迭代次数，与 **分块控制器** 状态机直接相关。

---

## 数据格式与内部位宽

```text
数据位宽 = 16（如 Q8.8 定点）
小数位 = 8
累加器位宽 = 40（点积中间结果防溢出）
指数输出位宽 = 24
分数中间位宽 = 40
```

**解析**：

- **16 bit 元素**：常见为 **Q8.8** 等定点；拓展实现可能支持 BF16/INT8，仍以参数与 RTL 分支为准。
- **宽累加器**：点积为 **多路乘加**，中间结果需 **防溢出**，再 **饱和/截断** 回 16 bit。
- **指数/分数路径**：与 **在线 Softmax**、**exp LUT**、**倒数** 等模块位宽一致，避免中间精度丢失。

---

## AXI 总线参数

```text
AXI 地址位宽 = 64，数据位宽 = 128，ID 位宽 = 4
AXI4-Lite 地址位宽 = 8，数据位宽 = 32
写选通位宽 = 数据位宽/8
```

**解析**：

- **主端口 AXI**：DMA 与高带宽数据搬运，宽数据、64 bit 地址符合 SoC 常见配置。
- **AXI4-Lite**：控制/状态寄存器 **按 32 bit 字访问**；地址空间小，偏移在表中列出。

---

## 寄存器地址映射（偏移）

| 偏移 | 用途 |
|------|------|
| `0x00` | 控制 |
| `0x04` | 状态 |
| `0x08` | 配置 |
| `0x14` ~ `0x30` | Q / K / V / O **基地址** 低 32 / 高 32 位各一组 |
| `0x34` | 行步长（byte stride） |
| `0x38` | 负大值（掩码/数值用常数） |
| `0x3C` | 缩放因子 |
| `0x40` | 周期计数（性能统计） |

**解析**：基址 **高低拆分** 是为在 32 bit AXI-Lite 数据位宽下拼出 **64 bit 指针**；行步长用于 **非紧密打包** 的矩阵布局。

---

## 控制 / 状态 / 配置位语义

```text
控制: 位0 启动脉冲，位1 软复位脉冲，位2 中断使能
状态: 位0 忙碌，位1 完成（粘滞），位2 错误
配置: 位0 因果掩码使能
```

**解析**：

- **启动/软复位** 多为 **写 1 触发、硬件自清** 或 **脉冲检测**，与 `AXI4精简从机` 实现一致。
- **完成粘滞**：软件需 **读清或写清**，避免漏掉单周期脉冲。
- **因果掩码**：决定 **点积/掩码单元** 是否对 `j > i` 位置施加 **负大值** 或屏蔽。

---

## 默认值

```text
行步长 = 头维度×2 字节
负大值、缩放因子为固定默认定点常数（与 RTL 中一致）
```

**解析**：`×2` 来自 **每元素 16 bit = 2 byte**；若数据格式改为 BF16/INT8，stride 与常数需与 RTL 同步修改。

---

## 并行度

```text
并行乘累加数 = 8（每周期同时累加 8 个乘积）
```

**解析**：与 **点积阵列**、**缓冲读端口宽度**、**控制器步进** 对齐；改变该参数会牵动阵列与缓冲端口的并行度。

---

## 指数相关表参数

```text
倒数单元用 LUT 深度 256、位宽 16 等（与 RTL 注释一致）
```

**解析**：与 **`exp_lut.hex` / `指数查找表ROM`** 及 **倒数近似** 路径配套；具体深度以头文件与 ROM 实例为准。

---

## 使用建议

修改竞赛/工程配置时，应 **只改 `fa_params.svh`（及依赖它的 testbench）** 并保持：**分块尺寸整除序列长度**、**缓冲深度 ≥ 分块元素数**、**AXI 宽度与每拍元素数一致**，否则易出现仿真对齐错误或缓冲区越界。
