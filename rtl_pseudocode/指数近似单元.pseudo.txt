// ============================================================
// 指数近似单元 — 中文伪代码（对应 exp_approx_unit.sv）
// ============================================================

模块: 指数近似单元（3 级流水线 + LUT）
输入: 时钟, 复位, 输入有效, 有符号定点 输入值, 负大值（兼容端口）
输出: 输出有效, 无符号定点 指数输出

查找表大小 = 1024，覆盖 x 约 [-16, +4]

// ----- 第 1 级（寄存输入侧索引） -----
组合:
  加16后的值 = 输入值 + 16（按输入小数位对齐的定点常数）
  索引计算值 = 加16后的值 / 5   // RTL 用近似除法映射到索引

时序 当 时钟上升沿:
  若 复位: 清空有效与截断标志
  否则:
    第1级有效 = 输入有效
    若 加16后的值 <= 0:        // x < -16
      索引 = 0, 下限截断 = 1
    否则若 索引计算值 >= 1024: // x > +4
      索引 = 1023, 上限截断 = 1
    否则:
      索引 = 索引计算值 的低 10 位, 截断标志 = 0

// ----- 第 2 级（ROM 读延迟对齐） -----
  第2级有效 = 第1级有效
  第2级查表值 = ROM(第1级索引)
  传递上下限截断标志

// ----- 第 3 级（输出与饱和） -----
  第3级有效 = 第2级有效
  若 下限截断: 结果 = 0
  否则若 上限截断: 结果 = 全1（最大）
  否则: 结果 = 第2级查表值

  输出有效 = 第3级有效
  指数输出 = 结果
