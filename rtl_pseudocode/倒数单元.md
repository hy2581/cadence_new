# 倒数近似单元 (`reciprocal_unit.sv`)

> 4 级流水线计算 1/x（Newton-Raphson 方法）。用于 Softmax 归一化中的除法运算。

---

## 接口

```pseudocode
输入: 无符号定点 被除数 d
输出: 无符号定点 倒数输出 ≈ 1/d
延迟: 4 个时钟周期
```

---

## 初始化（仿真时 LUT 生成）

```pseudocode
对 i = 0 到 255:
  归一化的 x = 0.5 + (i/256) × 0.5    // x ∈ [0.5, 1.0)
  倒数查找表[i] = round((1/x) × 2^FRAC_BITS)
```

> **解析**：LUT 只存储 [0.5, 1.0) 范围内的倒数。输入先归一化到这个范围，查表后再反归一化。

---

## 辅助函数

```pseudocode
函数 计算前导零数(值):
  从最高位向低位扫描，找到第一个为 1 的位
  返回左侧零的个数
  // 用于将输入归一化到 [0.5, 1.0) 的有效范围
```

---

## 4 级流水线

### 第 1 级：归一化

```pseudocode
保存原始 d
前导零数 = 计算前导零数(d)
移位量 = 前导零数
归一化值 = d << 前导零数    // 最高位对齐到 MSB
```

> **解析**：归一化使所有输入映射到相同的 [0.5, 1.0) 范围，使 LUT 只需 256 项。

### 第 2 级：LUT 查表

```pseudocode
查表索引 = 归一化值的高 8 位
初始猜测 x0 = 倒数查找表[查表索引] << 移位量
```

> **解析**：x0 是 1/d 的粗略估计，精度约 8 位。

### 第 3 级：Newton 迭代 1

```pseudocode
x1 = x0 × (2 - d × x0)
// 定点实现: 乘法后按 FRAC_BITS 右移对齐
```

> **解析**：Newton-Raphson 公式 `x_{n+1} = x_n × (2 - d × x_n)` 每次迭代精度翻倍。一次迭代后约 16 位精度。

### 第 4 级：Newton 迭代 2

```pseudocode
x2 = x1 × (2 - d × x1)
输出有效 = 第4级有效
倒数输出 = x2
```

> **解析**：两次迭代后精度约 32 位有效位，对 40-bit 定点运算足够。
