// ============================================================
// 输出累加器 — 中文伪代码（对应 output_accumulator.sv）
// ============================================================

模块: 输出累加器
功能: 每 KV 分块更新 O：
  首个分块: O 从零开始累加 P·V
  非首个: 先将旧 O 按缩放修正缩放，再累加 P·V
  末个分块: 再按分母和归一化并输出到 O输出

状态: 空闲 | 缩放旧值 | PV乘累加 | 归一化 | 处理完成

寄存器: O累加器[Q行][d列], V步进, 列基址
V总步数 = 头维度 / 并行列数

复位: 状态=空闲, O累加器清零

每拍: 完成=0, O有效=0

  空闲:
    若 启动:
      若 首个分块: 状态=PV乘累加, O累加器清零
      否则: 状态=缩放旧值
      忙碌=1, V步进=0, 列基址=0

  缩放旧值:
    对每行 r、每列 j:
      若 分母和[r]!=0:
        O累加器[r][j] = (O累加器[r][j] × 缩放修正[r]) >>> 小数位数
      否则 O累加器[r][j]=0
    状态=PV乘累加, V步进=0, 列基址=0

  PV乘累加:
    若 V有效:
      对每行 r、每个并行列偏移 p:
        PV和 = Σ_{c=0}^{KV行数-1} (P[r][c] × V[c][p]) >>> 小数位数
        O累加器[r][列基址+p] += PV和
      列基址 += 并行列数
      V步进++
      若 V步进 == V总步数-1:
        若 末个分块: 下一状态=归一化
        否则: 下一状态=处理完成

  归一化:
    对每行 r、每列 j:
      若 分母和[r]!=0:
        归一化值 = (O累加器[r][j] << 小数位数) / 分母和[r]
      否则 归一化值=0
      O输出[r][j] = 截断为数据位宽(归一化值 >>> (小数位数-8))  // Q8.8 输出
    状态=处理完成

  处理完成:
    O有效 = 末个分块   // 仅最后一块对外有效
    完成=1, 忙碌=0, 状态=空闲
