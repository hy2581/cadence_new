# 指数查找表 ROM (`exp_lut_rom.sv`)

> 1024 项只读查找表，存储 exp(x) 的定点近似值。支持仿真模式（完整 LUT）和综合模式（分段近似）。

---

## 接口

```pseudocode
输入: 地址 [9:0]    // 0..1023
输出: 数据 [23:0]   // 无符号定点 exp(x) × 2^FRAC_OUT
```

---

## 仿真模式

```pseudocode
初始化:
  对 i = 0 到 1023:
    x = -16.0 + i × (20.0/1024)      // 映射到 [-16, +4]
    e = exp(x)                         // 浮点计算
    数据[i] = min(饱和上限, round(e × 2^16))  // 转定点
读出:
  数据 = 查表存储器[地址]
```

> **解析**：x=-16 时 exp(-16) ≈ 1.1e-7 → 接近 0；x=+4 时 exp(4) ≈ 54.6 → 需要较宽的输出位宽。

---

## 综合模式

```pseudocode
// 用分段线性/分段常数近似替代 1024 项 ROM
// 按地址区间划分:
//   低区间(x < -10): 输出接近 0
//   中间区间: 线性插值
//   高区间(x > 2): 饱和为最大值
```

> **解析**：综合模式减少面积——用少量比较器和移位器替代大 ROM，代价是精度略降。
