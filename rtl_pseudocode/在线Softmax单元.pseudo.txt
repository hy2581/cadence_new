// ============================================================
// 在线 Softmax 单元 — 中文伪代码（对应 online_softmax_unit.sv）
// ============================================================

模块: 在线Softmax单元
输入: 分数矩阵 S[Q行][KV列], 首个分块, 旧最大值[], 旧分母和[]
输出: 新最大值[], 新分母和[], 概率矩阵 P（exp 定点）, 缩放修正[], 结果有效

子模块: 单个 指数近似单元，延迟 3 拍，逐元素时分复用

状态: 空闲 | 求行最大值 | 指数_输入 | 指数_等待 | 求和与修正 | 处理完成

计数器: 当前输入行/列, 当前输出行/列, 等待计数

复位: 全清零，状态=空闲

每拍:
  完成=0, 结果有效=0, 指数输入有效=0

  空闲:
    若 启动: 状态=求行最大值, 忙碌=1

  求行最大值:
    对每行 r:
      行最大 = max_j S[r][j]
      若 首个分块: 新最大值[r] = 行最大
      否则: 新最大值[r] = max(行最大, 旧最大值[r])
    输入/输出行列指针清零
    状态 = 指数_输入

  指数_输入:
    若 当前输入行 < Q行数:
      指数输入有效=1
      指数输入值 = S[当前输入行][当前输入列] - 新最大值[当前输入行]
      推进 (当前输入行, 当前输入列) 到下一元素
      等待计数++
      // 同时若 指数输出有效: 写入 P[当前输出行][当前输出列]，推进输出指针
    否则:
      指数输入有效=0
      状态 = 指数_等待   // 排空流水线

  指数_等待:
    若 指数输出有效: 同上写入 P 并推进指针
    若 当前输出行 >= Q行数 且 本拍无指数输出:
      状态 = 求和与修正

  求和与修正:
    对每行 r:
      行和 = Σ_j P[r][j]   // 宽位累加定点概率
      若 首个分块:
        新分母和[r] = 行和
        缩放修正[r] = 0
      否则:
        新分母和[r] = 旧分母和[r] + 行和
        缩放修正[r] = 旧分母和[r]   // 与 RTL 一致的简化
    状态 = 处理完成

  处理完成:
    结果有效=1, 完成=1, 忙碌=0, 状态=空闲
