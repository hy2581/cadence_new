// 分块控制器 — 中文伪代码（对应 tile_controller.sv）
// ============================================================

模块: 分块控制器

常量:
  Q分块总数 = 序列长度 / Q分块行数
  KV分块总数 = 序列长度 / KV分块行数
  Q/KV/O 分块字节数 = 行数×头维度×(数据位宽/8)

状态:
  空闲 → 加载Q → 等待Q加载 → 加载KV → 等待KV加载 → 启动计算 → 等待计算完成
  → 下一个KV → (循环加载KV或) 写回O → 等待O写回 → 下一个Q → 全部处理完成 → 空闲

寄存: Q索引, KV索引, KV缓冲选择（乒乓）

输出映射:
  Q分块索引 = Q索引, KV分块索引 = KV索引

复位: 全默认，DMA/计算请求=0

每拍: 全部完成=0, 计算启动=0, O回写启动=0

  空闲: 清 DMA 请求；若 启动: 状态=加载Q, 忙碌=1, Q/KV索引=0

  加载Q:
    DMA读请求=1, 地址=Q基+Q索引×行步长×Q分块行数, 长度=Q分块字节, 目标=Q
    状态=等待Q加载

  等待Q加载:
    DMA读请求=0；若 DMA读完成: KV索引=0, KV缓冲选择=0, 状态=加载KV

  加载KV:
    DMA读请求=1, 地址=K基+KV索引×行步长×KV分块行数, 长度=KV分块字节, 目标=K
    状态=等待KV加载

  等待KV加载:
    DMA读请求=0；若 DMA读完成:
      立即再发 DMA 读: V 基址+同样偏移, 目标=V, 状态=启动计算

  启动计算:
    DMA读请求=0；若 DMA读完成（V 加载完）:
      计算启动=1
      首个KV分块 = (KV索引==0)
      末个KV分块 = (KV索引==KV分块总数-1)
      状态=等待计算完成

  等待计算完成:
    若 计算完成: 状态=下一个KV

  下一个KV:
    若 KV索引已是最后一个:
      状态=写回O
    否则:
      KV索引++, KV缓冲选择取反, 状态=加载KV

  写回O:
    DMA写请求=1, 地址=O基+Q索引×行步长×Q分块行数, 长度=O分块字节
    O回写启动=1, 状态=等待O写回

  等待O写回:
    若 DMA写完成: DMA写请求=0, 状态=下一个Q

  下一个Q:
    若 Q索引已是最后一个: 状态=全部处理完成
    否则: Q索引++, 状态=加载Q

  全部处理完成:
    全部完成=1, 忙碌=0, 状态=空闲
