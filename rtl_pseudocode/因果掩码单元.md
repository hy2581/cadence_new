# 因果掩码单元 (`causal_mask_unit.sv`)

> 纯组合逻辑模块。判断注意力矩阵中每个 (行, 列) 位置是否需要被掩码。

---

## 接口

```pseudocode
输入:
  causal_en       // 因果掩码使能
  Q分块索引        // 当前 Q-tile 的索引 (0..63)
  KV分块索引       // 当前 KV-tile 的索引 (0..15)
  分块内行号       // tile 内的行号 (0..TILE_BR-1)
  分块内列号       // tile 内的列号 (0..TILE_BC-1)
输出:
  mask             // true = 该位置应被掩码（填 NEG_LARGE）
```

---

## 核心逻辑

```pseudocode
绝对行号 = Q分块索引 × TILE_BR + 分块内行号
绝对列号 = KV分块索引 × TILE_BC + 分块内列号

若 causal_en 且 绝对列号 > 绝对行号:
  mask = true     // 该 token 不允许看到"未来"的 token
否则:
  mask = false
```

> **解析**：因果注意力（Causal Attention）要求位置 i 的 token 只能关注位置 j ≤ i 的 token。当 j > i 时，对应的 score 被替换为 NEG_LARGE（-128.0 in Q8.8），经过 exp() 后趋近于 0，从而在 softmax 中被"屏蔽"。

---

## 举例

```
序列长度=8, 因果掩码矩阵（0=可看, X=屏蔽）:
     K0 K1 K2 K3 K4 K5 K6 K7
Q0 [ 0  X  X  X  X  X  X  X ]   ← Q0 只能看 K0
Q1 [ 0  0  X  X  X  X  X  X ]   ← Q1 能看 K0,K1
Q2 [ 0  0  0  X  X  X  X  X ]
...
Q7 [ 0  0  0  0  0  0  0  0 ]   ← Q7 能看所有 K
```
