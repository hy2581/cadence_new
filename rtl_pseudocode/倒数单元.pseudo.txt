模块: 倒数近似单元（牛顿迭代，4 级流水线）
输入: 时钟, 复位, 输入有效, 无符号定点 被除数 d
输出: 输出有效, 无符号定点 倒数输出 ≈ 1/d

// 初始化（仿真）: 256 项 LUT
对 i 在 0..255:
  归一化区间内的 x = 0.5 + (i/256)×0.5
  倒数查找表[i] = round( (1/x) × 2^小数位数 )

函数 计算前导零数(值):
  从最高位向低位找第一个为 1 的位，返回左侧零的个数（用于归一化）

// ----- 第 1 级 -----
时序:
  有效1 = 输入有效
  保存原始被除数 = d
  前导零数 = 计算前导零数(d)
  移位量 = 前导零数
  归一化值 = d << 前导零数   // 使最高位为 1

// ----- 第 2 级 -----
时序:
  有效2 = 有效1
  传递 被除数、移位量
  查表索引 = 归一化值的高 8 位
  初始猜测 x0 = 倒数查找表[查表索引] << 移位量

// ----- 第 3 级：牛顿 1 -----
  x1 = x0 × (2 - d×x0)   // 定点：乘后按小数位右移对齐
  传递 d

// ----- 第 4 级：牛顿 2 -----
  x2 = x1 × (2 - d×x1)

  输出有效 = 第4级有效
  倒数输出 = x2
