# 输出累加器 (`output_accumulator.sv`)

> 跨 KV-tile 累加 O = P · V。非首个 tile 需要先缩放旧 O，最后一个 tile 做归一化输出。

---

## 状态机

```pseudocode
空闲 → 缩放旧值 → PV乘累加 → 归一化 → 完成
```

- **首个 tile**：跳过缩放，直接进入 PV 乘累加
- **中间 tile**：缩放旧 O → PV 乘累加 → 完成
- **最后 tile**：缩放旧 O → PV 乘累加 → 归一化 → 完成

---

## 各阶段

### 缩放旧值（非首个 tile）

```pseudocode
对每行 r, 每列 j:
  若 l_new[r] != 0:
    O_acc[r][j] = (O_acc[r][j] × rescale[r]) >>> FRAC_BITS
  否则:
    O_acc[r][j] = 0
```

> **解析**：当新的 KV-tile 改变了 max 值时，之前累加的 O 需要按 `l_old/l_new` 缩放。RTL 中简化为乘 `rescale = l_old`，最后归一化时再除 `l_new`。

### PV 乘累加

```pseudocode
V总步数 = HEAD_DIM / PAR_COLS = 64/8 = 8 步

每步(当V有效时):
  对每行 r, 每个并行列偏移 p:
    PV和 = Σ_{c=0}^{TILE_BC-1} P[r][c] × V[c][列基址+p]
    PV和 = PV和 >>> FRAC_BITS
    O_acc[r][列基址+p] += PV和
  列基址 += PAR_COLS
  V步进++
```

> **解析**：P 是 4×16 的概率矩阵，V 是 16×64 的值矩阵。P·V 得到 4×64 的结果，逐步累加到 O。

### 归一化（仅最后 KV-tile）

```pseudocode
对每行 r, 每列 j:
  若 l_new[r] != 0:
    归一化值 = (O_acc[r][j] << FRAC_BITS) / l_new[r]
  否则:
    归一化值 = 0
  O_out[r][j] = 截断为 DATA_WIDTH(归一化值 >>> (FRAC_BITS-8))
```

> **解析**：最终除以 l（softmax 分母和）完成归一化。`>>> (FRAC_BITS-8)` 将内部 FRAC=16 的精度转回 Q8.8 输出格式。

### 完成

```pseudocode
O有效 = 末个分块标志    // 只有最后一个 KV-tile 才产生有效输出
完成=1, 忙碌=0, 状态=空闲
```

> **解析**：O 在中间 KV-tile 时是"半成品"（尚未归一化），只有所有 KV-tile 都处理完，才是最终结果。
