# FlashAttention 顶层 (`flash_attention_top.sv`)

> 顶层互连模块，将 5 个主要子模块连接在一起。本身不包含算法逻辑。

## 参数

来自 `fa_params.svh`：序列长度(256)、头维度(64)、分块大小(BR=4,BC=16)、AXI 宽度(128bit)等。

---

## 子模块实例与连接关系

### 1) AXI4-Lite 从机

```pseudocode
对外: 完整 AXI4-Lite 从机端口（主机通过此接口配置寄存器）
对内输出: 启动、软复位、中断使能、因果掩码使能
         Q/K/V/O 基址(64bit)、行步长、负大值、缩放因子
对内输入: 状态_忙碌、状态_完成、状态_错误、周期计数
附加逻辑: 完成清除(W1C)、中断信号
```

> **解析**：主机先写寄存器配置好参数（基地址、scale 等），然后写 CTRL[0]=1 触发 START 脉冲。计算完成后读 STATUS 和 CYCLES。

### 2) 分块控制器

```pseudocode
启动        ← 寄存器_启动
基址/行步长  ← 寄存器输出
DMA 读写    ↔ DMA引擎（请求、地址、长度、目标）
计算控制    ↔ 计算核心（启动、首/末 KV、Q/KV 分块索引）
KV缓冲选择  → 缓冲系统（乒乓切换）
O回写完成   ← DMA写完成（assign 直连）
```

> **解析**：分块控制器是整个流水线的"调度器"，负责外层 Q-tile 循环和内层 KV-tile 循环，以及 DMA 数据传输的时序控制。

### 3) DMA 引擎

```pseudocode
AXI4 主机全信号 ↔ 片外总线
读完成时: 按目标(0=Q,1=K,2=V)写入对应缓冲
写回时:   从 O 缓冲按拍读出数据发送到 AXI 总线
```

> **解析**：DMA 引擎是数据搬运工——从片外内存加载 Q/K/V tile 到片上缓冲，计算完成后把 O tile 写回内存。

### 4) 缓冲系统

```pseudocode
DMA 写:     Q/K/V 缓冲（K/V 带乒乓选择）
计算核心读:  Q/K/V 缓冲（K/V 读选择通常为 ~写选择，实现读写交错）
O 写:       计算核心的 O有效 信号触发整块 O 写入
O 读:       DMA 回写时按行/列组读出
```

> **解析**：乒乓缓冲是关键优化——DMA 写一侧缓冲的同时，计算核心读另一侧，实现数据传输和计算的重叠。

### 5) 计算核心

```pseudocode
输入: 启动/首末KV/分块索引/掩码/缩放/负大值 ← 控制器与寄存器
数据: Q/K/V 读端口 ↔ 缓冲系统
输出: O分块、O有效 → 缓冲系统
```

> **解析**：计算核心编排一个 (Q-tile, KV-tile) 对的完整流水线：点积 → 掩码 → softmax → 累加。

## 辅助逻辑

### 周期计数器

```pseudocode
若 复位:         计数 = 0
否则若 寄存器_启动: 计数 = 0    // START 时重置
否则若 控制器_忙碌: 计数++     // 运行期间计数
```

> **解析**：从 START 到 DONE 的总周期数，主机可通过 CYCLES 寄存器(0x40)读取，用于性能评估。

### 状态信号

```pseudocode
状态_忙碌 = 控制器_忙碌
状态_完成 = 控制器_全部完成
状态_错误 = 0  // RTL 占位，未实现错误检测
```

> **解析**：顶层只做互连与简单赋值，**所有算法逻辑在计算核心及其子模块中完成**。
