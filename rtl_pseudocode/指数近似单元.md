# 指数近似单元 (`exp_approx_unit.sv`)

> 3 级流水线定点 exp(x) 近似。使用 1024 项查找表，覆盖 x ∈ [-16, +4] 范围。

---

## 参数

```pseudocode
查找表大小 = 1024 项
覆盖范围: x ∈ [-16.0, +4.0]
步长: 20.0/1024 ≈ 0.01953
输出格式: 无符号定点 Q(OUT_WIDTH-FRAC_OUT).FRAC_OUT
```

---

## 流水线

### 第 1 级（索引计算）

```pseudocode
组合逻辑:
  加16后的值 = x + 16 × 2^FRAC_IN    // 偏移到正数范围
  索引计算值 = 加16后的值 / 5          // 近似映射到 0..1023

时序逻辑:
  若 加16后的值 ≤ 0:           // x < -16.0
    索引=0, 下限截断=1          // exp(-16) ≈ 0
  否则若 索引计算值 ≥ 1024:     // x > +4.0
    索引=1023, 上限截断=1       // exp(4) 饱和到最大值
  否则:
    索引=计算值[9:0], 截断=0
```

> **解析**：除以 5 是对 `20/1024 ≈ 0.01953` 的简化近似。精确映射应是 `(x+16) × 51.2`，但硬件除法更简单。

### 第 2 级（ROM 查表）

```pseudocode
查表值 = exp_lut_rom[第1级索引]    // 组合读取 ROM
传递截断标志
```

### 第 3 级（输出选择）

```pseudocode
若 下限截断: 结果 = 0           // exp(x < -16) ≈ 0
否则若 上限截断: 结果 = 全1     // exp(x > 4) = 最大值
否则: 结果 = 查表值             // 正常 LUT 输出
```

> **解析**：最大相对误差约 1.56%。对于 attention 的 softmax 计算，这个精度已经足够。
