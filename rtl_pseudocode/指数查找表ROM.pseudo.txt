模块: 指数查找表ROM
输入: 地址 [9:0]  // 0..1023
输出: 数据 [23:0] // 表示 exp(x)×65536 一类的定点结果

若 综合模式 (SYNTHESIS):
  // 用分段线性/分段常数近似代替完整 1024 项 ROM
  根据 地址 落在的区间，用若干线性公式或常数计算 数据
  低 x 区输出接近 0；高 x 区饱和为最大值

否则 仿真模式:
  初始化:
    对 i 从 0 到 1023:
      x = -16 + i × (20/1024)
      e = exp(x)
      数据[i] = min( 饱和上限, round(e × 65536) )
  读出:
    数据 = 查表存储器[地址]
