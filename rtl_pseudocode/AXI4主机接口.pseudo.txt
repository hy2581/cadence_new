// ============================================================
// AXI4 主机接口 — 中文伪代码（对应 axi4_master_if.sv）
// ============================================================

模块: AXI4主机接口
作用: 把 DMA 的「读/写请求 + 地址 + 字节长度」变成标准 AXI4 突发事务

常量:
  每拍字节数 = 数据位宽/8
  大小编码 = log2(每拍字节数)
固定输出: INCR 突发、全写选通、写响应始终就绪、ID=0 等

// ---------- 读通道状态机 ----------
状态: 读_空闲 | 读_发地址 | 读_接收数据 | 读_完成
变量: 读总节拍数, 读节拍计数

复位: 读状态=空闲, 地址有效=0, 读数据就绪=0, 读完成=0, 读出数据有效=0

每拍 读完成=0, 读出数据有效=0

  读_空闲:
    若 读请求:
      读总节拍数 = ceil(读长度字节 / 每拍字节数)
      主机读地址=读地址, 突发长度=读总节拍数-1, 读地址有效=1
      读节拍计数=0, 状态=读_发地址

  读_发地址:
    若 主机读地址就绪:
      读地址有效=0, 读数据就绪=1, 状态=读_接收数据

  读_接收数据:
    若 读数据有效且就绪握手:
      读出数据 = 主机读数据, 读出数据有效=1, 读节拍计数++
      若 主机读最后一拍: 读数据就绪=0, 状态=读_完成

  读_完成:
    读完成=1, 状态=读_空闲

// ---------- 写通道状态机 ----------
状态: 写_空闲 | 写_发地址 | 写_发送数据 | 写_完成
变量: 写总节拍数, 写节拍计数

  写_空闲:
    若 写请求: 同上算节拍, 发写地址, 状态=写_发地址

  写_发地址:
    若 写地址就绪: 写地址有效=0, 写入数据就绪=1, 状态=写_发送数据

  写_发送数据:
    主机写数据 = 写入数据, 写数据有效 = 写入数据有效
    若 写入数据有效: 写节拍计数++, 最后一拍标志 = (写节拍计数==写总节拍数-1)
    若 写数据有效且就绪且最后一拍:
      清写数据有效/最后一拍/写入数据就绪, 状态=写_完成

  写_完成:
    若 写响应有效: 写完成=1, 状态=写_空闲
