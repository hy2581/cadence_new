# 计算核心 (`compute_core.sv`)

> 编排一个 (Q-tile, KV-tile) 对的完整计算流水线：点积 → 掩码 → 在线Softmax → 输出累加。

---

## 子模块

```pseudocode
dot_product_array    → 计算 S = Q·K^T × scale
causal_mask_unit     → 因果掩码（组合逻辑，内嵌在 FSM 中）
online_softmax_unit  → 在线 Softmax
output_accumulator   → P·V 乘累加 + 最终归一化
```

---

## 状态机

```pseudocode
空闲 → 点积计算 → 掩码处理 → Softmax → 累加 → 完成
```

---

## 跨 KV-tile 持久寄存器

```pseudocode
旧最大值 m_old[每行]    // 初始: 负无穷（{WIDTH{1'b1}}）
旧分母和 l_old[每行]    // 初始: 0

更新时机:
  Softmax结果有效时: m_old ← m_new, l_old ← l_new
  首个KV且启动时:    重置为初始值
```

> **解析**：这两个寄存器是 Online Softmax 的核心——它们在 KV-tile 间传递 running max 和 running sum，使得不需要存储完整的注意力矩阵。

---

## 各阶段详解

### 点积计算

```pseudocode
点积启动=1, 步进=0
循环:
  Q/K 读使能=1
  Q/K 读步进=当前步进  // 每步读 PAR_MACS 个元素
  点积数据有效=1
  步进++
直到 点积完成 → 状态=掩码处理
```

### 掩码处理（单周期组合逻辑）

```pseudocode
对每个 (行r, 列c):
  绝对行 = Q分块索引 × TILE_BR + r
  绝对列 = KV分块索引 × TILE_BC + c
  若 因果掩码使能 且 绝对列 > 绝对行:
    masked_score[r][c] = 符号扩展(NEG_LARGE)  // -128.0 in Q8.8
  否则:
    masked_score[r][c] = 点积分数[r][c]
Softmax启动=1, 状态=Softmax
```

> **解析**：因果掩码确保 token i 只能关注 token j ≤ i。被掩码的位置填入 NEG_LARGE，经过 exp() 后趋近于 0。

### Softmax

```pseudocode
等待 Softmax完成 → 累加启动=1, V步进=0, 状态=累加
```

### 累加

```pseudocode
循环:
  V读使能=1, V读步进=当前步进, V有效=1
  步进++
直到 累加完成 → 状态=完成
```

### 输出

```pseudocode
O分块, O有效 由输出累加器在最后一个KV-tile处理完成后拉高
```
